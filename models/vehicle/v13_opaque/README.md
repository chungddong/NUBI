## 무엇을 왜 바꿨나

요청: 반투명은 쓰지 않는다 — 투명하지 않은 불투명으로.

- 바닥판: 투명 PC 5t → **불투명 PC 5t** (흑색 · 회색). 형상 · 구멍 그대로.
- 앞 · 뒤판: UV PC 3t → **불투명 UV PC 3t**. 옆판 ACM 은 원래 불투명.
- 뷰어 · 기록 이미지도 반투명 표시를 없앴다.
- 기록 도구가 형상이 같고 색만 바뀐 것도 "색·재질 변경" 으로 잡게 했다 (이번 변화가 그렇다).
