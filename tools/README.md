# tools — PC 쪽 개발 · 분석 도구

여러 계층에 걸쳐 쓰는 도구를 둡니다. 예: 주행 로그 분석, 속도 · 전류 계산, 보드에 파일 동기화.

한 펌웨어에만 쓰는 도구(바퀴 제어기 GUI `hoverctl.py` 등)는 그 펌웨어의 `tools/`에 둡니다.

## 규칙

- 파일 하나로 도는 스크립트는 맨 위 docstring에 용도와 실행 예를 적습니다.
- Python 도구는 저장소 루트의 venv 하나를 같이 씁니다. 의존성은 `tools/requirements.txt`에 적습니다.
- 도구를 추가하면 아래 표에 한 줄 적습니다.
