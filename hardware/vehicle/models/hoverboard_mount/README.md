# 호버보드 허브모터 휠 마운트 (3030 기본, EXTRUSION 으로 교체)

호버보드 6.5" 허브모터를 T슬롯 알루미늄 프로파일에 다는 마운트. build123d 로 짠
파라메트릭 CAD 이고, **축 치수 몇 개만 실측값으로 바꾸면 STEP 을 그대로 가공
업체에 넘길 수 있는 수준**을 목표로 했다.

```bash
.venv\Scripts\python.exe models\hoverboard_mount\export.py      # STEP/STL + 검증
.venv\Scripts\python.exe models\hoverboard_mount\prototype.py   # 프린트 fitment 판
```

## 네 설계안

프로파일이 **면당 슬롯 몇 줄인가**로 갈린다. 기울임 모멘트(800N x 53.7mm = 43 N·m)를
볼트 인발이 아닌 경로로 보내야 하는데, 그 방법이 시리즈마다 다르다.

| 설계 | 프로파일 | 기울임을 받는 법 | 부피 |
|---|---|---|---|
| **D 하단 클램프** | **3030** (1줄) | 옆면 슬롯에 **전단** — 플랜지 2장 커플 | 143 cm³ |
| C 새들 | 3060 (2줄) | 슬롯 2줄 커플 | 186 cm³ |
| A 스플릿+어댑터 | 3060/4080 | 어댑터 판 → 슬롯 2줄 | 218 cm³ |
| B 토크판+어댑터 | 3060/4080 | 어댑터 판 → 슬롯 2줄 | 173 cm³ |

**실물 프레임이 3030 이므로 Design D 가 기본이다.** A/B 는 어댑터 판이 슬롯 2줄에
물리는 걸 전제로 해서 3030 에서는 성립하지 않는다 (`export.py` 가 건너뛴다).

### Design D — 기존 클램프 + 새 하부 클램프, 레일 밑에 매단다 (권장)

```
low_clamp   92.7 x 46.6 x 63.9   143 cm³   6061-T6   387 g   탭 M6 x4
+ 기존 호버보드 클램프 (상부 절반, 이미 손에 4개 있다)
볼트: 밑면 M6x20 x2 (깊은 카운터보어) / 옆면 M6x20 x4 / 상하 클램프 M6 x4
```

기존 클램프가 D컷을 물어 반력토크를 받고, 새 하부 클램프가 축을 반원으로 받친다.
둘을 M6 x4 로 물린 덩어리를 레일 밑면에 매단다. 다리 2개가 상부 클램프를 타고 넘어
레일까지 올라가고, 그 위쪽이 **레일 3면(밑면 + 양 옆면)** 을 잡는다.

**옆면을 왜 잡나.** 3030 은 면당 슬롯이 1줄이라 밑면 볼트 2개가 같은 y 에 있다.
피벗(레일 밑모서리)까지 지레가 15mm 뿐이라 볼트당 1432 N 인발 — M6 스프링너트
보수 하한(1500 N)의 **96%** 다. 실물이 부러진 것과 같은 경로다. 옆 플랜지를 두면
같은 모멘트가 플랜지 2장의 **수직 전단 커플**(지레 30mm)로 가고 716 N,
M6 전단(8000 N)의 **9%** 로 떨어진다. 볼트 4개 더 박는 값이다.

800N 사용률:

```
레일 밑면 볼트 인발   1432 N / 1500 =  96%   ← 이것만으로 받는 경우
레일 옆면 볼트 전단    716 N / 8000 =   9%   ← 플랜지가 받는 경우 (실제 경로)
다리 굽힘             2.5 MPa / 240 =   1%
블록 굽힘 (다리 스팬)  4.8 MPa / 240 =   2%
축 시트 면압          1.2 MPa / 120 =   1%
상부 클램프 볼트 전단  378 N / 8000 =   5%   (구동 반력 29 N·m)
```

두 경로 모두 "혼자 다 받는다"고 본 보수값이다. 실제로는 전단 경로가 훨씬 뻣뻣해서
— 볼트가 슬롯 벽에 바로 닿는다 — 너트가 휘어야 힘이 느는 인발보다 먼저 받는다.
`LOW_SIDE = False` 로 플랜지를 끄면 인발 96% 만 남는다. **끄지 마라.**

**바깥 윤곽이 각기둥 하나다.** 처음엔 블록 + 다리 + 플랜지를 따로 쌓았더니
플랜지(바깥면 ±23.3)가 몸체(±20)보다 3.3mm 튀어나오고, z=14.5 에서 18x40 기둥이
갑자기 18x8 지느러미로 줄어드는 단차가 생겼다 — 가공 중에 떨리기 좋은 형상이다.
지금은 92.7 x 46.6 x 63.9 각기둥에서 셋만 파낸다:

```
① 다리 사이 통로 44.7   기존 클램프가 위에서 수직으로 내려가는 길
② 레일 홈 30.6          레일이 X 로 지나가는 길
③ 축 반원 시트 Ø16.2
```

다리 폭도 18 → 24 로 키웠다 (굽힘 4.5 → 2.5 MPa). 통로 폭은 기존 클램프 폭
(42.72) + 2 로 유도하므로, 다리를 더 안으로 밀 수는 없다 — 밀면 클램프가 안 들어간다.

**조립 순서가 강제된다.** 상부 클램프 볼트는 위에서 조여야 하는데 레일이 2mm 위에
있다. 그래서: ① 축을 하부 시트에 앉히고 ② 상부 클램프를 M6 x4 로 조인 뒤
③ 레일 슬롯에 스프링너트를 넣고 조립체를 레일 끝에서 밀어 끼우고
④ 밑면 2볼트(카운터보어로 아래에서) + 옆면 4볼트를 조인다.

### Design C — CNC 알루미늄 통짜 새들 브라켓 (3060 전용)

```
saddle_bracket   186 cm³   6061-T6 통짜   586 g   탭 M6 x4
+ 기존 호버보드 클램프 (상부 절반, 이미 손에 있다)
```

**실물 브라켓이 부러진 뒤 처음부터 다시 설계한 것이다.** 부러진 구조는 프레임이
축보다 91mm 위에 있고 무보강 10mm 판이 그 거리를 외팔보로 버티는 형태였다.
800N(사람이 올라탐)에서 그 판의 응력은 PETG 항복의 119% 였다.

바뀐 것:

| | 부러진 것 | Design C |
|---|---|---|
| 레일 위치 | 축보다 91mm 위 | **축 옆** — 외팔보가 없다 |
| 기울임 반력 | 슬롯 1줄 → 볼트 인발 | 슬롯 **2줄** + 레일 밑모서리 지지 |
| 상부 절반 | 새로 만듦 | **기존 클램프 재사용** (채널 5.07 = D컷 평면) |
| 얇은 판 | 무보강 10mm 외팔보 | 통짜 — 무보강 판이 없다 |
| 탭 | 8곳 | **4곳** (레일쪽은 T너트라 탭 0) |

800N 기준 사용률:

```
레일볼트 윗줄  430 N 인장   M6 스프링너트 1500N 의 29%
레일볼트 아랫줄 143 N 인장                        10%
새들 뿌리 굽힘  2.1 MPa     6061-T6 240MPa 의  1%
백플레이트 굽힘 8.6 MPa                          4%
구동토크 반력   242 N 전단  M6 전단 8000N 의    3%
```

지레가 어디서 나오나: 백플레이트가 레일 바깥면에 눌리는 접촉점이 **레일 밑모서리**에
잡힌다. 거기서 윗줄까지 45mm, 아랫줄까지 15mm. 두 줄이 거리에 비례해 인장을 나눈다.
1줄짜리(3030)면 이 지레가 없어서 전부 인발로 몰린다 — 부러진 것과 같은 경로다.

**핀치갭 0.4** 이 이 설계의 유일한 비직관적 치수다. 기존 클램프의 채널(5.07)이
D컷 평면(5.0)보다 0.07 깊어서, 새들 윗면을 그만큼 낮추지 않으면 클램프가 축이
아니라 새들에 먼저 앉는다 — 볼트만 조여지고 축은 그냥 미끄러진다.

## 앞선 두 설계안



### Design A — CNC 알루미늄 2피스 스플릿 클램프

```
axle_clamp_upper   47.6 cm³   6061-T6
axle_clamp_lower   62.0 cm³   6061-T6
```

축을 상·하 블록이 감싸고, 포켓 내부가 D컷과 맞물려 반력토크를 받는다.

- **장점** — 축을 360° 감싸 축방향 구속(마찰)이 자연히 생긴다. 가·감속 양방향
  토크를 포켓 양면이 받는다. 강성이 제일 높다.
- **단점** — 3축 밀링이 필요하다. 부피가 커서 가공비가 든다.
- **핵심 치수** — `CLAMP_PINCH_GAP = 0.8`. 상·하 사이에 틈이 없으면 축을 물기
  전에 두 블록이 먼저 맞닿아 조임이 안 걸린다.
- `CLAMP_FIT = 0.05` — **크게 주면 안 된다.** 역토크에서 덜컹거린다.

### Design B — 레이저 절단 강판 토크 플레이트

```
torque_plate    50.2 cm³   5~6mm 강판 2D 절단
axle_retainer   13.9 cm³   분할 칼라
```

D컷과 꼭 맞는 컷아웃 하나로 토크를 받는다.

- **장점** — 2D 절단만으로 나온다. 제일 싸다. 강판이라 재료 여유가 크다.
- **단점** — **평판은 축방향을 못 막는다.** 그래서 분할 칼라가 필수다.
  면압이 판 두께에만 걸려 국부 변형 위험이 A 보다 크다.

### 무엇을 고를까

**시험 단계는 B, 확정되면 A** 를 권한다. B 는 축 치수가 틀려도 다시 자르는 값이
싸고, A 는 치수가 확정된 뒤에 만들어야 아깝지 않다.

## 구조 원칙

| 항목 | 어떻게 |
|---|---|
| 토크 반력 | 포켓/컷아웃이 D컷과 **형상으로** 맞물린다. 마찰 체결에 안 기댄다 |
| 양방향 토크 | 포켓 여유 0.05mm — 가속·제동 양쪽 면이 다 닿는다 |
| 축방향 구속 | A: 클램프 마찰 / B: 분할 칼라 + 어댑터 **카운터보어**(안쪽 이동 차단) |
| 케이블 | 어댑터에 관통공. 축 구멍은 카운터보어라 케이블만 빠져나간다 |
| 하중 분산 | 어댑터 플레이트가 받아 4080 의 **슬롯 2줄**로 나눈다 |

### 왜 어댑터 플레이트를 따로 두나

클램프를 프로파일에 직접 붙이면 (1) 하중이 좁은 면에 몰리고 (2) 클램프만 교체할
수 없고 (3) 나중에 서스펜션으로 못 바꾼다. 판 하나를 사이에 두면 셋 다 풀린다.
`§10` 확장 경로는 이 판을 피벗 브래킷으로 갈아끼우는 것이다.

### 4080 을 쓰는 이유

80mm 면에 T슬롯이 **2줄**(간격 40) 있다. 볼트가 높이차 40mm 로 벌어져서, 수직
하중이 축 오프셋만큼 만드는 기울임 모멘트를 긴 지레로 받는다. 30 계열 1줄로는
그 모멘트가 볼트 인발로 몰린다.

## 검증 (export.py 가 매번 돌린다)

```
[Design A] 부품 13개  문제 없음
[Design B] 부품 13개  문제 없음
```

- 모든 제작 부품 **솔리드 1개** (조각남 없음)
- 부품 전 조합 간섭 검사 (체결 짝은 예외 목록)
- 축이 포켓에 들어가는가 / 클램프가 모터 하우징과 안 부딪히는가
- 케이블 통로 확보
- 볼트·공구 접근성 — **T너트 볼트를 클램프 밖(±50)으로 뺐다.** ±35 였을 때
  클램프(±38) 밑에 깔려 조일 수가 없었다
- 최소 두께 3mm 검사

### 설계 중에 잡은 것

| 문제 | 원인 |
|---|---|
| 축이 두 조각 / 모터가 엉뚱한 자리 / 포켓이 클램프 밖 | `Plane.XZ` 법선이 **-Y** 인데 offset 부호를 세 번 틀렸다 → `plane_at_y()` 로 봉인 |
| 축이 어댑터 판을 5.9mm 파고듦 | 판에 축·케이블 구멍이 없었다 → 카운터보어 |
| T너트 볼트를 조일 수 없음 | 클램프 밑에 깔림 → 볼트 간격 70→100, 판 폭을 볼트 간격에서 유도 |
| Design B 토크판이 32mm 떠 있음 | 클램프 자리에 세웠다 → 어댑터 바깥면에 맞댐 |
| 리테이너가 프로파일과 4430mm³ | 평판을 어댑터 안쪽에 붙이려 했다 → **평판은 축방향을 못 막는다**. 분할 칼라로 교체 |
| 볼트 머리끼리 겹침 | z 간격 12 < 머리 Ø13.6 → 16 으로 |

## 프로토타입 (프린트)

```
prototype_axle_clamp_upper / _lower   축 포켓 여유 0.05 → 0.35 (FDM 수축 보정)
```

> **3D printed clamp is intended for fitment and assembly verification only,
> not as the final load-bearing motor mount.**

프린트판으로 확인할 것: 축이 포켓에 들어가는가 / 볼트 위치가 맞는가 / 케이블이
