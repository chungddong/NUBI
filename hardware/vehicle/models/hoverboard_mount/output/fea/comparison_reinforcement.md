# 보강 형태 비교 — Design D 하부 클램프 FEA

800 N 상향 · 편심 55 mm · 3 mm C3D10 · PETG 근사 (E 2100, 항복 45) — 이름에 AL6061 이 붙은 줄만 알루미늄.
레일 볼트 구멍 벽 강체 고정, 타이는 접지 스프링, 선반·날개 볼트도 강체 고정.
혀(tongue) 줄의 '조인트' 는 혀 볼트 구멍 벽을 **z 접지 스프링**(볼트당 K: 경제형 스프링너트 23,430 / 드롭인 T너트 98,415 N/mm)
으로 바꾼 것 — H 크로스가 통째로 내려가는 것을 잡는 크로스 양 끝 브라켓 조인트의 무름을 넣는다 (`SHELF_JOINT_K`).
그 줄에서 구멍 벽 x/y 는 자유이고, '+ y 스프링/잠금' 줄은 같은 벽에 y 접지 스프링(`SHELF_JOINT_KY`)을 더한 민감도다.
**캠버**가 실물에서 보이는 '바깥으로 벌어짐'이다 — 축이 옆으로 밀리는 양(시트 Uy)보다 훨씬 크다.

## 참고

- **선반 v1** (축만 피하는 20mm 노치): 캠버 +9.902 mrad (4.7×) / 최대변위 0.3929 / 구조응력 89.8 MPa (200%) —
  노치 옆벽이 몸체 가운데 토막 윗면(z=-0.4)과 만나는 모서리 한 점에 몰렸다. v2 는 노치를 다리 사이 통로 폭(44.7)으로
  넓히고 R4 를 줬다. 응력은 130% 로 내려왔지만 몸체 가운데 토막과의 연결이 없어져 강성은 4.7× → 3.9× 로 줄었다.
  v2 의 남은 최대점은 선반 뿌리가 다리 안쪽면과 만나는 모서리(x=±22.4, y=-77, z≈-5)다. 선반 판 자체는 34 MPa (75%).
- **옛 ㄷ자 브라켓 (실제로 부러진 것, legacy_u_nogusset)**: 같은 조건에서 최대 44.4 MPa / 2.979 mm.
- 옆 날개는 FEA 에서 구멍 벽을 강체로 잡아 뿌리 응력이 18 MPa 로 낮게 나온다. 실물이 부러진 건 **층간 접착**(등방성
  모델에 없다)과 뿌리의 날카로운 모서리 때문이라 이 표의 40% 를 믿으면 안 된다.
- 레일볼트/추가고정 열은 구멍 벽 반력의 z 합이다. 레일 구멍의 음수 반력은 다리 윗면 지압(누름)이 섞인 값이지 볼트
  인장이 아니다. 선반 구멍의 양수 반력(≈700 N)은 선반이 아래로 벌어지려는 것을 볼트가 잡는 값 = 크로스 슬롯 인발 하중이다
  (볼트당 ≈350 N, 스프링너트 보수 한계 1500 의 23%).
- **혀 조인트 스프링 (2026-09-16)**: 혀 볼트 구멍 벽을 z 접지 스프링으로 바꾸면 (x/y 자유) 캠버 7.44 → 11.46 mrad 로
  54% 늘어나는데, 스프링을 4.2 배 뻣뻣하게 (23,430 → 98,415) 해도 11.20 이라 **거의 안 변한다.** 조인트 z 무름 자체의
  몫은 작다: 같은 K 에 y 만 잠그면 (`_ky10000000`) 7.78 mrad (강체 대비 +4.6%). 나머지 +47% 는 강체 고정이 혀 구멍
  벽 **y 방향**까지 잡아 주던 경로가 사라진 값이다 — 강체 케이스에서 혀 구멍 벽 Fy = -732 N, 레일 볼트 +732 N 으로
  혀가 y 스트럿(EA/L ≈ 54 kN/mm, PETG) 노릇을 했다. 실물에서 이 경로는 혀 윗면 마찰 → 크로스 축력 → 끝 브라켓 →
  레일 → 레일 볼트로 닫히는 고리라 유한하다. y 에 K 와 같은 스프링을 달면 (`_ky23430`) 8.08 mrad. **PETG 혀의
  캠버는 조인트보다 y 경로 가정에 훨씬 민감하다.** AL6061 은 혀가 뻣뻣해서 조인트 몫이 커진다: 강체 선반 0.355 →
  스프링너트 조인트 혀 0.519 mrad (혀 볼트 스프링 처짐 0.009/0.013 mm).
  구조응력 최대점은 여섯 케이스 모두 축 끝 포켓 모서리(x=±10, y=-77, z=-0.4) — 혀 구멍에서 14.7 mm 라 스프링 노드
  집중력이 아니고, 제외 반경 3→8 mm 로 값이 안 변한다. y 자유 케이스에서 44.8 MPa (100%) 로 오르는 것은 y 스트럿이
  포켓 모서리 굽힘을 덜어 주던 몫이다. 스프링 반력은 RF 에 안 찍혀 -K/n·ΣUz 로 계산했고, .dat 의 SHELF_HOLE_n U 합과
  일치하며 (478.189 / 238.262 N), 반력 총합 Fz 는 여섯 케이스 모두 -800.000 ± 0.002 N 이다.
