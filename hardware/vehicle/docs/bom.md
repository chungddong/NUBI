# 차량 전체 버전 — BOM / 예상 견적

`tools/bom/bom.py` 가 **모델 형상에서 직접** 뽑는다. 형상을 고치고 다시 돌리면
수량·부피·질량이 따라온다. 손으로 고칠 곳은 스크립트 맨 위 `PRICE` 표뿐이다.

- 구성: `PAYLOAD=cargo` 전체 버전 (프레임 + Design-D 휠마운트 + 외장셸 + 적재함)
- 전장 873 x 전폭 612 x 전고 606 mm
- 뷰어: `.venv/Scripts/python.exe models/hoverboard_mount/vehicle_cargo_integration.py`

## 대안 — 큰 셸을 판재로 바꾸면

셸 4가지가 출력 시간의 대부분을 먹고, 그러면서 베드에 하나도 안 들어간다.
같은 부피를 벽 두께로 나눠 전개 면적을 내고 3mm 판재로 환산했다.
(굽힘·용접·리벳 공수와 치공구는 안 넣었다 — 면적 값만이다.)

판재로 가면 부품값 292,427원과 출력 309시간이

## 가정 — 여기가 틀리면 견적이 틀린다

1. **단가는 `확인` 태그만 실주문 값이다.** 3030 프로파일 950원/100mm,
   다이캐스팅 브라켓 3025 360원, M6x15 70원, 스프링너트 306 180원.
   나머지는 전부 시장가 눈대중이라 실제 견적과 배는 차이날 수 있다.
2. **보유 판정**은 지금까지의 실물 상태를 따랐다 — 프레임 프로파일·철물,
   허브모터 4개, 기존 상부 클램프 4개, M6x15 볼트, 스프링너트, 남는 390mm
   3030 프로파일, 배터리팩. 새로 만드는 거면 '전부 신품' 합계를 봐라.
3. **출력 부품 값은 필라멘트 값뿐이다.** 실패분·서포트·전기·프린터 감가는
   안 넣었다. 실무로는 여기에 30~50% 를 더 얹는다.
4. **판재 두께·재질은 가정이다** (PC/ABS 3mm). 면적은 형상에서 나왔지만
   실제로는 1220x2440 장으로 사서 자르니 남는 값을 더 내게 된다.
5. **외장셸·적재함을 출력으로 잡았다.** 합쳐 11 L 가 넘어서 여기가 전체
   출력 시간의 대부분이다. 진공성형이나 ABS 판재 절곡으로 가면 시간이
   급감하는 대신 금형·치공구가 붙는다.
6. **범퍼를 TPU 로 잡았다.** 고무 범퍼 스트립을 사서 붙이는 게 더 쌀 수 있다.
7. **베드 초과 부품은 분할 비용을 안 넣었다.** 조각을 붙일 다월·접착·보강판이
   추가로 들고, 이음선이 곧 약한 면이 된다.
8. **인건비·배송비·부가세 없음.** 부품값만이다.
