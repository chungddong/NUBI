# data — 데이터

| 폴더 | 무엇을 | git |
| --- | --- | --- |
| `raw/` | 센서 원본: rosbag, 카메라 이미지, 깊이 프레임 | ✗ |
| `processed/` | 원본을 가공한 결과: 추출 프레임, 라벨, 학습용 세트 | ✗ |
| `logs/` | 주행 로그, 텔레메트리 CSV, 시리얼 로그 | ✗ |
| `maps/` | SLAM 맵 (`.pgm` + `.yaml`) | ✓ |
| `calibration/` | 카메라 내부 · 외부 파라미터, IMU 보정값 | ✓ |

✗ 폴더는 `.gitignore`로 막아 두었습니다. 폴더 구조만 git에 남고 내용은 이 PC나 외부 저장소에
둡니다. 대용량 데이터를 따로 보관할 곳(외장 디스크, NAS, 클라우드)은 아직 정하지 않았습니다.

## 이름 규칙

데이터 세트 하나에 폴더 하나, 이름은 `YYYY-MM-DD_<장소>_<내용>`입니다.

```
raw/2026-10-20_lab_depth-guard-test/
logs/2026-10-20_hallway_first-drive/
```

## 데이터 세트마다 남길 것

폴더 안에 `README.md`를 두고 아래를 적습니다. 이 파일은 git에 올라가도록 예외 처리해 두었습니다.

- 언제, 어디서, 어떤 하드웨어 구성으로 (펌웨어 커밋, 센서, 구동 모드)
- 무엇을 하려고 모았는지
- 파일 목록과 형식
- 문제가 있었던 구간
