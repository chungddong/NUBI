# worklog — 작업 기록

한 달에 파일 하나(`YYYY-MM.md`)를 쓰고, 작업한 날마다 섹션을 추가합니다.

```markdown
## 2026-10-13 — 작업 주제

- 어디서: PC / Jetson "dongki" / RDK "sunrise" / 시제품
- 한 것:
- 확인한 것: (수치, 측정 조건)
- 남은 일:
```

결정은 [decisions/](../decisions/)에, 긴 디버깅 과정은 [troubleshooting/](../troubleshooting/)에 따로
쓰고 여기서는 링크만 겁니다.
