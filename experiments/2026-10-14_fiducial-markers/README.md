# 2026-10-14 · 복도에 마커 (AprilTag) 를 붙여 위치 바로잡기

> 상태: **진행 중** — 2026-10-14 바닥에 깐 마커로 첫 시험 (아래 결과). 다음은 벽에 세워 붙이기.

## 1. 목적

카메라 사진만으로 위치를 찾는 SfM 지도 ([../2026-10-13_sfm-relocalization](../2026-10-13_sfm-relocalization/README.md)) 는
첫 주행 (2026-10-14) 에서 지도 영상과 같은 방향일 때만 잘 됐다 (웹캠 갈 때 80 ~ 90 %, 돌아올 때 0 %). 지도가 없는 방향 ·
어두운 곳 · 로비 입구처럼 비슷한 곳에서 틀린 답이 나는 곳을 마커로 메울 수 있는지 본다.

- 마커 하나를 사진 한 장에서 찾으면 카메라 자세 (위치 · 방향) 가 바로 나온다 — 어느 방향에서 보든, 지도 영상과 상관없이.
- 찾기가 빠르다 (SfM 매칭 1 s 에 비해 수십 ms) · 틀린 답이 거의 없다 (36h11 은 ID 사이 거리가 멀다).
- 대신 복도에 붙여 두어야 하고 (학교 허락 · 떨어지거나 떼일 수 있다), 붙인 자리를 지도 좌표로 알아야 한다.

## 2. 구성

- 마커: AprilTag 36h11, ID 0 ~ 11, 검은 사각 바깥 한 변 **160 mm** (A4 한 장에 하나, 둘레 흰 여백 25 mm ≥ 마커 한 칸 20 mm).
  `python markers.py sheet` → `print/apriltag36h11_160mm.pdf` (git 밖 — 언제든 다시 만든다). 100 % 로 인쇄해 50 mm 막대로 확인.
- 카메라: 차의 웹캠 (1280 × 720, 가로 화각 약 70° — 첫 주행에서 SfM 으로 추정) · Xtion 컬러 (640 × 480, 58.6°).
  160 mm 마커가 한 변 30 px 로 보이는 거리: 웹캠 약 4.9 m, Xtion 약 3.0 m.
- 코드: `markers.py` — 인쇄 · 사진에서 찾기 (`detect`), 마커 자세 (`tag_pose`, OpenCV `SOLVEPNP_IPPE_SQUARE`).
  OpenCV aruco 는 PC (5.0) · Jetson (4.5.4) 둘 다 있다 (옛 함수 / 새 클래스를 가려 쓴다).
