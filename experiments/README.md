# experiments — 실험 · 프로토타입

정식 코드로 들어가기 전의 실험을 둡니다. 실험 하나에 폴더 하나, 이름은 `YYYY-MM-DD_<주제>`입니다.

```
experiments/
├── 2026-09-17_depth-guard/           RDK + Xtion 전방 장애물 가드 (가져올 예정)
├── 2026-09-18_flysim-drive/          Jetson 초파리 전뇌 시뮬레이션 폐루프 주행 (가져올 예정)
├── 2026-10-13_vlm-drive/             Jetson + ESP32 + 깊이 카메라로 GPT · Claude 실차 운전 (Jetson 실기 점검 · 바퀴 방향까지)
└── 2026-10-13_sfm-relocalization/    복도 SfM 지도로 카메라 위치 다시 찾기 정확도 (미완)
```

## 실험 폴더마다 남길 것

`README.md`에 아래 네 가지를 적습니다.

1. **목적** — 무엇을 확인하려 했는지
2. **구성** — 어느 보드에서, 어떤 하드웨어 · 펌웨어로
3. **결과** — 수치와 관찰
4. **결론** — 계속할지, 정식 코드로 옮길지, 버릴지

## 정식 코드로 옮길 때

자리를 잡은 실험은 `software/`나 `firmware/`로 옮기고, 실험 폴더 README에 옮긴 위치를 적어
둡니다. 실험 폴더는 기록으로 남겨 둡니다.

실험 중 생긴 대용량 데이터는 여기 두지 않고 [data/](../data/)에 둡니다.
